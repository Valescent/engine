# v0.0.2 scope: Camera

**Status:** Complete.

**Goal:** Fly through the existing cube scene with keyboard and mouse, and measure frame time while moving.

This page expands the [v0.0.2 roadmap entry](../roadmap.md#v002-camera) into concrete deliverables. The roadmap remains the source of truth for milestone status and the Definition of Done.

## Definition of Done

- Fly smoothly through the cube scene with WASD and mouse look.
- `Escape` releases the cursor without closing the window.
- Movement is independent of frame rate and the camera survives resizes.
- Frame time stays stable while moving.
- The existing `Space` voxel toggle still works.

## In scope

- First-person fly camera with position, yaw, and pitch.
- Pitch clamped to ±89°.
- WASD movement relative to the view direction.
- Mouse look with pointer capture.
- `Escape` releases the cursor; losing focus clears held keys and capture.
- Delta-time movement and continuous redraw while focused.
- Frame-time logging while moving.
- CPU-only camera math tests.

## Out of scope

- Collision, gravity, jumping, and walking (v0.0.4).
- Voxel raycasting, block highlighting, and place/destroy (v0.0.4).
- Chunks, meshing, and face culling (v0.0.3).
- Textures, block types, lighting, and persistence.

## Technical shape

### Camera state

- `position: Vec3`, `yaw: f32`, `pitch: f32`.
- Right-handed, Y-up; yaw `0` looks down `-Z`.
- Pitch is clamped to ±89° to keep the view direction well-defined.
- Forward, right, and up vectors are derived from yaw and pitch.
- `view_projection()` uses the current aspect ratio, 60° field of view, and 0.1–100 m range.
- Default speed is 8 units per second; default sensitivity is 0.0025 radians per pixel.

### Input

- WASD is read from physical key codes so keyboard layout does not change movement.
- W/S move along the camera's view direction; A/D strafe right and left.
- Mouse look reads raw mouse motion only while the cursor is captured.
- A left click captures the cursor and hides it.
- `Escape` releases the cursor and shows it again.
- Losing window focus releases capture and clears all held movement keys.

### Frame loop

- The application stores the previous frame `Instant` and computes a delta each frame.
- Delta is clamped (for example, to 100 ms) so a stalled frame cannot teleport the camera.
- The camera uniform is rewritten before rendering.
- The next frame is requested continuously while the window is focused.
- Resizing updates the aspect ratio and the projection.
- Frame time is logged at debug level about once per second.

### Controls

| Input | Action |
|---|---|
| `W` / `S` | Move forward / back along the view direction |
| `A` / `D` | Strafe left / right |
| Mouse | Look around while captured |
| Left click | Capture the cursor |
| `Escape` | Release the cursor |
| `Space` | Toggle the existing demo voxel |

### Code shape

- Move camera state and math into `src/camera.rs`; keep input and the frame loop in `src/lib.rs`.
- Keep the existing renderer, pipeline, and voxel scene unchanged.
- Add unit tests beside the camera math; no GPU or window is required.
