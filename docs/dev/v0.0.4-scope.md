# v0.0.4 scope: Playable

**Status:** Scoped; implementation not started.

**Goal:** Walk through the chunked world, break and place blocks, and keep edits across restarts.

This page expands the [v0.0.4 roadmap entry](../roadmap.md#v004-playable) into concrete deliverables. The roadmap remains the source of truth for milestone status and the Definition of Done.

## Definition of Done

- The player walks on terrain, falls under gravity, jumps, and cannot pass through solid blocks.
- The targeted block has a visible outline.
- Left click breaks a block and right click places the selected block.
- Breaking and placing update only the affected chunk meshes.
- The world reloads with the same blocks after an engine restart.

## In scope

- Player movement with gravity, jumping, and swept AABB collision.
- A walking controller built on the v0.0.2 camera.
- Block types, a hotbar, and solid/air queries.
- DDA voxel raycasting from the eye.
- A wireframe highlight around the targeted block.
- Break and place interaction with chunk rebuilds.
- Block textures in one texture array with per-face layers.
- Chunk persistence: save on exit and load on startup.
- CPU-only tests for collision, raycasting, block storage, and save/load.

## Out of scope

- Infinite terrain streaming and generated terrain (v0.0.7).
- Lighting, fog, water, and transparency (v0.0.6).
- LOD, greedy meshing, and async meshing (v0.0.5).
- Swimming, inventory UI, crafting, and multiplayer.

## Technical shape

### Block model

- Replace the per-chunk `HashSet<IVec3>` with `HashMap<IVec3, Block>`.
- Start with `Air`, `Stone`, `Dirt`, `Grass`, `Wood`, and `Leaves`.
- `Block::is_solid` controls collision, face culling, and raycasts.
- The initial scene uses grass on top and dirt below, with a small stone/wood arrangement.

### Player and collision

- Player AABB: 0.6 m wide, 1.8 m tall; eye at 1.62 m.
- Walk speed 4.5 m/s, gravity 24 m/s², jump velocity 8 m/s.
- `Space` jumps; WASD walks; mouse look remains from v0.0.2.
- Resolve movement one axis at a time with a swept AABB against solid voxel AABBs.
- Spawn above the ground and never start inside a solid block.
- Do not add step-up or slopes; jumping handles single-block ledges.

### Raycast and interaction

- DDA traversal from the eye along the view direction, maximum 6 m.
- Return the first solid voxel and the face normal used for placement.
- Block interaction requires the cursor to be captured.
- The first left click after the cursor is released captures only; it does not break or place.
- Capture is acquired by left click only; right click is not a capture button.
- Once captured, left click breaks and right click places the selected block in the adjacent
  cell.
- Reject placement if the cell is occupied or the new block intersects the player.
- Draw the highlight as a wireframe cube with a line-list pipeline.
- Breaking and placing reuse the v0.0.3 dirty-chunk rebuild path.

### Textures and hotbar

- Store block textures in one `texture_2d_array`, one 16×16 layer per tile.
- Use a texture array rather than a flat 2D atlas so greedy quads stay tileable in v0.0.5.
- Generate placeholder tiles procedurally; no image asset pipeline yet.
- Use nearest filtering and no mipmaps.
- Number keys `1`–`5` select stone, dirt, grass, wood, or leaves.
- Each block face maps to a layer: grass uses different top, side, and bottom layers.

### Persistence

- Store one file per non-empty chunk under `world/chunks/`.
- Format: magic `VCHK`, format version, chunk coordinates, block count, then `(x, y, z, block)` records.
- Use little-endian integers and local coordinates from `0` to `31`.
- Load every chunk file at startup; save every non-empty chunk on exit and on `Ctrl+S`.
- Reject malformed or unknown-version files with a typed error and a clear message.
- Treat a missing `world/` directory as an empty world and create it on first save.
- Add `world/` to `.gitignore`.
- Record the save format in a new ADR before implementing persistence.

### Code shape

- `src/block.rs` — block enum and texture-layer mapping.
- `src/player.rs` — gravity, movement, and swept AABB collision.
- `src/world.rs` — chunk and block storage, plus save/load integration.
- `src/raycast.rs` — DDA voxel traversal and hit result.
- `src/renderer.rs` — texture array, highlight pass, and updated vertex layout.
- `src/voxel.rs` — texture-aware and highlight mesh generation.
- `src/lib.rs` — input, interaction, and wiring.

## Acceptance checklist

- [ ] Walking, falling, jumping, and collision behave correctly on flat and uneven terrain.
- [ ] The player cannot tunnel through blocks at normal speed or frame times.
- [ ] The target outline follows the crosshair and disappears when nothing is in range.
- [ ] Left click breaks the targeted block; right click places the selected block.
- [ ] Placement is rejected inside the player or an occupied cell.
- [ ] Blocks use the correct texture tile on every face.
- [ ] Saving, closing, and reopening restores the edited world.
- [ ] A malformed chunk file produces a clear error instead of a panic.
- [ ] `cargo fmt --all -- --check`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo test --all-features`, `cargo doc --no-deps --all-features`, `typos`, and `mdbook build` pass.
- [ ] The README and roadmap are current and `CHANGELOG.md` has the user-visible entries.

## Deliberate simplifications

| Simplification | Revisit when |
|---|---|
| Axis-separated swept AABB, no slopes or step-up | Movement feels too limited or terrain generation arrives. |
| No swimming or water collision | Water arrives in v0.0.6. |
| Procedural placeholder texture tiles | A real asset pipeline is introduced. |
| One world directory and one file per chunk | Streaming or compression needs a different layout. |
| Save on exit and `Ctrl+S` only | Autosave or crash recovery is needed. |
| No inventory UI; number keys select blocks | Inventory or survival mechanics arrive. |

## Relationship to later milestones

- v0.0.5 replaces naive meshing with greedy meshing, LOD, frustum culling, and async rebuilds.
- v0.0.6 adds lighting, day/night, fog, and water on top of the playable world.
- v0.0.7 generates terrain and streams chunks through the save/load and async systems.
