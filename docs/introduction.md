# Valescent Engine

A voxel engine written in Rust.

**Status: pre-alpha.** `0.0.1` is the foundation milestone: a window, a camera, and cubes drawn from a voxel set rather than hardcoded draw calls. Nothing beyond that is built yet.

Valescent Engine is **source-available, not open source**.
