# Bundled fonts

These `woff2` subsets are served by the documentation site:

- **Anybody** — [Etcetera Type Co.](https://github.com/Etcetera-Type-Co/Anybody)
- **Public Sans** — [U.S. Web Design System](https://github.com/uswds/public-sans)
- **Spline Sans Mono** — [Sorkin Type](https://github.com/SorkinType/SplineSansMono)

All three are distributed under the [SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/). The latin subsets were downloaded from Google Fonts.
