## How the score works

| Source | Weight |
|---|---:|
| Roadmap box ticked | 25 XP |
| Release tagged | 250 XP |
| Commit | 5 XP |
| Test in `src/` | 2 XP |

500 XP per level. The weights favour finished, verifiable work over raw churn.
